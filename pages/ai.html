Usage

$ acg ai "what does this repo do?"
This project is a web crawler that indexes...
 
$ acg ai "how do I add a new spider?"
Create a new file in spiders/ that extends...
 
$ acg ai "explain the deploy process"
The deploy script in scripts/deploy.sh...

Configuration

# acg.yaml
ai:
provider: local # local | anthropic | openai
model: phi3 # model name
context_files: # files always included as context
- README.md
- acg.yaml
- src/main.py
system_prompt: |
You are an AI assistant for this project.
The project is: {description}
Be concise. Under 100 words.

How It Works

1. Reads context_files from acg.yaml (first 2000 chars each)
2. Prepends system_prompt ({description} is auto-replaced)
3. Sends prompt + context to the configured provider
4. Prints the response to stdout

Example Configs by Provider

Local (Ollama)

ai:
provider: local
model: phi3 # or llama3, mistral, etc.

Anthropic (Claude)

ai:
provider: anthropic
model: claude-sonnet-4-20250514
# export ANTHROPIC_API_KEY=sk-ant-...

OpenAI

ai:
provider: openai
model: gpt-4o-mini
# export OPENAI_API_KEY=sk-...
Context files are truncated to 2000 characters each. The {description} placeholder in system_prompt is replaced with the project description from acg.yaml.
