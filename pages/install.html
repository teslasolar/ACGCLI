Install

$ npm install -g acg-cli

Requires Node.js 16+

Quick Start

$ cd my-project
$ acg init
ℋ Created acg.yaml for my-project (python)
Edit the file, then run: acg status
 
$ acg status
✓ acg.yaml valid
✓ git repo
✓ commands defined
✓ runtime specified
4 passed · 0 failed
 
# now use it
$ acg run
$ acg test
$ acg build

Auto-Detection

acg init scans your repo root and picks the right runtime template:

Python

Detected by: requirements.txt or pyproject.toml

Node.js

Detected by: package.json

Rust

Detected by: Cargo.toml

Go

Detected by: go.mod

Static

Detected by: index.html

What acg init Creates

A single acg.yaml file with:
 
• name (from directory name)
• runtime (auto-detected)
• commands: run, test, build, deploy, lint, clean
• api config (port 9000)
• mcp config
• ai config (local/ollama default)
 
Edit the commands to match your actual project.

Start All Three Layers

# CLI — just use commands directly
$ acg run
$ acg test
 
# API — HTTP server
$ acg api start
ℋ ACG API server on :9000
 
# MCP — for AI assistants
$ acg mcp start
ℋ ACG MCP server running: 12 tools
acg init will not overwrite an existing acg.yaml. Edit it directly or delete it first to re-scaffold.
