Install

$ npm install -g acg-cli

Requires Node.js 16+

Quick Start

$ cd my-project && acg init
ℋ Created acg.yaml for my-project (python)
$ acg status
4 passed · 0 failed
$ acg run
$ acg test

Auto-Detection

Static

All Three Layers

$ acg run # CLI — direct commands
$ acg api start # API — HTTP on :9000
$ acg mcp start # MCP — AI tools over stdio
acg init will not overwrite an existing acg.yaml. Delete it first to re-scaffold.
