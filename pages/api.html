Built-in Endpoints

MethodPathDescription
GET/statusProject name, version, status
GET/healthSimple health check
GET/configFull acg.yaml config as JSON
GET/logsRecent git log (20 entries)

Auto-generated Endpoints

Every command in commands: and custom: becomes a POST endpoint.

MethodPathRuns
POST/runcommands.run.cmd
POST/testcommands.test.cmd
POST/buildcommands.build.cmd
POST/deploycommands.deploy.cmd
POST/lintcommands.lint.cmd
POST/cleancommands.clean.cmd
POST/{custom}custom.{name}.cmd

Response Format

// Success
{ "ok": true, "command": "test", "output": "..." }
 
// Failure
{ "ok": false, "command": "test", "error": "..." }

Example: curl

$ curl http://localhost:9000/status
{"name":"my-project","version":"1.0.0","status":"ok"}
 
$ curl -X POST http://localhost:9000/test
{"ok":true,"command":"test","output":"4 passed\n"}

Configuration

# acg.yaml
api:
port: 9000 # server port
cors: true # enable CORS
CORS is enabled by default. The API server runs Express with JSON body parsing. All command endpoints have a 60-second timeout.
