What is MCP?

The Model Context Protocol lets AI assistants call tools in your project. ACG-CLI auto-generates an MCP server from your acg.yaml — giving Claude (or any MCP client) direct access to your repo's commands, files, and git state.

Extra Tools

Define additional MCP tools in acg.yaml with custom commands and parameters.

# acg.yaml
mcp:
name: my-project-mcp
extra_tools:
- name: search_index
description: "Search the index"
params: { query: string }
cmd: python scripts/search.py --query "{query}"
The MCP server runs over stdio. Command tools have a 60-second timeout. File paths are resolved relative to the repo root.
